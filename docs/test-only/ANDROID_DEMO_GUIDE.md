# دليل تجربة تطبيق أولياء الأمور — نسخة Debug فقط

هذه الحسابات محلية داخل نسخة Android Debug ذات الحزمة `sd.alumrabi.parent.debug`. لا تستخدم Supabase ولا تتصل بقاعدة بيانات المدرسة، ولا تظهر في نسخة Release. بياناتها اصطناعية بالكامل.

## الحسابات

| نوع الحساب | معرّف الحساب | كلمة المرور |
|---|---|---|
| أسرة متعددة الأبناء | `DEMO-FAMILY-01` | `demo2026` |
| ولي أمر لديه ابن واحد | `DEMO-SINGLE-01` | `demo2026` |

حساب الأسرة يعرض أربعة أبناء موزعين على الروضة والمرحلة الأساسية والمتوسطة والثانوية، مع أمثلة للنتائج والحضور والرسوم والإعلانات والتقويم. الحساب الآخر يعرض ابناً واحداً لاختبار اختلاف عدد الأبناء.

## حدود الاختبار

- تظهر علامة «وضع تجريبي — بيانات غير حقيقية» في لوحة التحكم.
- لا تُحفظ بيانات الدخول التجريبية كجلسة ولا تُرسل إلى الخادم.
- تنتهي جلسة العرض عند إغلاق التطبيق، ويمكن تسجيل الدخول مجدداً.
- لا تختبر هذه الحسابات المصادقة الحقيقية أو صلاحيات RLS أو عزل البيانات في الخادم.
- يوجد ملف SQL منفصل `docs/test-only/SEED_200_COMPREHENSIVE_STUDENTS.sql` لبيئة قاعدة بيانات اختبار فقط؛ يحتوي بيانات اصطناعية لنحو 210 طلاب و110 أولياء أمور. لم يُنفّذ هذا الملف على أي قاعدة بيانات ضمن تحديث التطبيق. لا تشغّله على الإنتاج.

## بناء APK

من مجلد `android-parent-app` نفّذ `./gradlew assembleDebug`. الناتج: `app/build/outputs/apk/debug/app-debug.apk`.
