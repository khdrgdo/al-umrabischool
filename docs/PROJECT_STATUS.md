## 1. جدول الوضع العام للمكونات

| المكوّن | الحالة القائمة | الدليل الفني | الملاحظات والفجوات |
| :--- | :---: | :--- | :--- |
| **قاعدة البيانات الأساسية (0000–0004)** | **مطبّق على الحية** | استعلام REST 200 على: `schools`, `academic_years`, `grades`, `sections`, `students`, `enrollments`, `attendance_sessions`, `attendance_records`, `subjects`, `audit_log`, `profiles`, `user_roles`. | الجداول فارغة (count = 0) ومحمية بـ RLS. |
| **قاعدة البيانات الموسعة (0005–0009)** | **ملف موجود (غير مطبّق على الحية)** | استعلام REST أرجع 404 لـ: `guardians`, `student_payments`, `fee_structures`, `student_grades`, `assessments`, `announcements`. | تتطلب مراجعة التعديلات الإلزامية (المرحلة 3) قبل التطبيق على الإنتاج. |
| **مجموعات الاختبارات الآلية (10 أجنحة)** | **اختبار آلي ناجح (10/10)** | تشغيل Vitest الآلي: `10 passed, 49 passed (57.34s)`. خلو تام من التمرير الوهمي. | تغطي: الرقم المدرسي، الصلاحيات، المسارات والـSSR، مصادقة أولياء الأمور، عزل الأبناء، سرية الرسوم، الدرجات، نسب الحضور، تكامل الجدول، وبيئة Cloudflare. |
| **بناء تطبيق الويب (SSR & Nitro Module)** | **اختبار آلي ناجح** | أمر `bun run build` انتهى بكود `0` بدون أخطاء. خرج الحزمة في `.output/`. | يدعم Cloudflare Worker Preset مع حارس SSR لمنع خطأ 500 في Lovable Cloud. |
| **أتمتة CI/CD (GitHub Actions)** | **ملف موجود** | `.github/workflows/ci.yml` تم تحديثه مع توليد `package-lock.json` وربط فحص TypeScript وVitest وبناء Android. | يحتاج تفعيل Dependabot وCodeQL من إعدادات مستودع GitHub. |
| **تطبيق الهاتف لأولياء الأمور (Android)** | **مطبّق ومثبّت على جهاز فعلي** | بناء `gradlew assembleDebug` بنجاح وتثبيت APK عبر ADB على جهاز Realme RMX3710 (Android 15)، والتقاط لقطات شاشات حية للهوية والأيقونة وشاشة البداية والجدول. | تفعيل Supabase Auth الكامل مع Edge Functions معلّق على بوابات الأمان والموافقة (المرحلة A3). |
| **سكريبت البيانات التجريبية الشاملة** | **ملف موجود (محمي بحارس أمان)** | نُقل إلى `docs/test-only/SEED_COMPREHENSIVE_TEST_DATA.sql` مع حارس SQL يمنع تشغيله إذا وُجد طالب حقيقي. | ممنوع التطبيق على الإنتاج لحين توفير بيئة staging. |
