# ORB-V2 — Premium Redesign

- Version key: ORB-V2
- Android version: 2.0.0
- Branch: feature/orb-v2-premium-redesign
- Debug package: sd.alumrabi.parent.debug

## Design system
- Deep evergreen institutional primary, warm ivory surfaces, restrained brass accent.
- One emblem across launcher icon, splash, sign-in and parent dashboard.
- RTL-first hierarchy, readable typography, touch targets at least 48dp.
- Material 3 component patterns, consistent geometry and clear connection/demo states.
- Dashboard prioritizes child selection, academic identity, attendance and published services.

## Boundaries
- No production database changes or migrations.
- Demo accounts remain local Debug-only data.
- This is not a production release; official brand artwork and release signing key are still required.
- Build status is determined only by the matching GitHub Actions run and artifact.
